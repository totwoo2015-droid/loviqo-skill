# Loviqo Skill

English | [简体中文](README.zh-CN.md)

Agent Skill for Loviqo notes, recordings and to-dos. Hosted MCP at `https://api.loviqo.com/mcp` with **OAuth by default** (no API Key required for Claude Code / ChatGPT / Claude connectors).

## One-line setup

```
Install the Loviqo skill from https://github.com/totwoo2015-droid/loviqo-skill and connect my notes
```

The agent installs the skill, adds the MCP server, and opens a browser for Loviqo sign-in.

## MCP URL

```
https://api.loviqo.com/mcp
```

Prefer OAuth. API Key is only a fallback for clients that cannot do browser auth.
